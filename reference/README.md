# Reference material

Raw design and brand source material, kept for ongoing content/design work. Not used directly by the app.

- `bolt-mockup/` — the original Bolt.new-generated Vite+React+TS prototype (public site + mock admin view). Used as a structural/content reference for later stages, not ported directly into the Next.js app (different styling approach — plain CSS instead of Tailwind/shadcn).
- `flyers/` — WhatsApp marketing flyer images. Source of the real Damview brand identity: logo line-art, color palette, menu items/pricing, facility list, contact numbers, location.
- `documents/` — `invoice.pdf` and `receipt.pdf`, reference layouts for the future invoice/receipt document module (Stage 10).
